# Shop Commands

Shop Commands provides operational WordPress Abilities for WooCommerce Shop
Managers. Its initial development milestone focuses on read-only order
information.

The first Ability is:

- `shop-commands/orders-needing-attention` — returns counts of processing,
  on-hold, and failed WooCommerce orders.

## Requirements

- WordPress 6.9 or later
- PHP 7.4 or later
- WooCommerce

Shop Commands is currently developed and tested inside the MadraK9 project.
It defines store capabilities and structured data contracts, and exposes
supported Abilities through a reusable WordPress Command Palette and result
modal integration.
